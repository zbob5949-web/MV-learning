

## 一、成果说明

### 摘要

这篇综述写的是拍照/扫描文档图像的质量问题，主要盯偏色和光照不匀两类。选题来自平时拍作业、
试卷和板书的实际困扰：同一页纸在暖光灯和窗光下拍出来颜色完全不同，手臂挡住的地方又暗一块，
OCR 在这两种情况下都容易出错。文章先把基础铺了一遍——图像怎么读进来、RGB/灰度/HSV/Lab 四种
颜色空间各自适合干什么、直方图和均值方差这些统计量能描述哪些退化；然后比较了直方图均衡化、
CLAHE、白平衡、伽马校正和 Retinex 这几类校正方法的适用条件。着重点是物理先验：文档纸张的
反射率接近中性且大面积平滑，所以成像方程 I=LR+n 里的低频分量 L 基本就是光源色温和阴影造成的
照度分布。把 L 估计出来，偏色和光照不匀就能分开判断，而不是混成一句"这张图太暗了"。最后按要求
设计了 240 张、四类对象各 60 张的采集方案。

### 正文

综述正文约 2700 字，分摘要、引言、方法脉络、对比讨论、数据收集方案、结论六部分，参考文献 7 篇。
方法脉络拆成四块：2.1 颜色空间讲 RGB 加权灰度、HSV、Lab 的用途和坑，比如通道顺序读错会把蓝色
偏移误判成红色偏移；2.2 统计特征讲直方图、均值方差、对比度和色偏度量，偏色这里我特意只统计近白
背景像素，免得深色文字和彩色插图把均值带偏；2.3 按是否用到空间信息把五类校正方法排了一下；
2.4 物理先验讲成像方程和照度-反射分解怎么解释前面的现象。结论是倾向分层处理：先快速筛查，再算
Lab 和照度指标，然后按问题类型挑校正手段，最后拿 OCR 错误率和版面分割指标回头验证，而不是无脑
全局拉对比度——全局拉伸会把阴影边缘和纸张纹理一起放大。数据收集方案是 240 张，作业、试卷、板书、
插图四类各 60 张，双人标注加加权 Kappa 和 ICC 做一致性检验。

### 复现步骤

配套代码就一个文件 `document_image_analysis.py`，实现正文 2.1/2.2/2.4 节的 9 项质量指标。
不依赖 OpenCV 和 scipy，只用 numpy + Pillow，Laplacian 和低频照度都是自己用数组切片写的。

```bash
# 环境：Python >= 3.8，必需 numpy、pillow；matplotlib 仅 --figures 时需要
python document_image_analysis.py aebd26820104da5ac76f8c38e696dc9b.jpg --out_dir out_demo --figures
```

产物（均在 `out_demo/`）：

- `metrics.json` —— 9 项指标（尺寸、RGB/灰度均值、对比度、Laplacian 方差清晰度、
  背景偏色 a\*/b\*、低频照度不均匀度）；
- `gray_histogram.png` —— 灰度直方图（纯 Pillow 绘制）；
- `report_figure.png` —— 报告图 1 的 2×2 展示图（原图 + 直方图 + 低频照度伪彩 + 指标卡）；
- 终端同时打印同一份 JSON。

拿我自己拍的一张作业照片实测（6048×4024）：

| 指标 | 实测值 | 判读 |
|---|---|---|
| `gray_mean` | 49.314 | 平均亮度很低，属严重欠曝 |
| `gray_std_contrast` | 47.02 | 对比度偏低，与欠曝一致 |
| `laplacian_variance_sharpness` | 205.041 | 标准 4-邻域 Laplacian 响应方差 |
| `lab_background_a_offset` | −38.411 | 近白区 R 明显低于 G，红-绿轴强偏移 |
| `lab_background_b_offset` | 1.804 | 黄-蓝轴基本正常 |
| `illumination_nonuniformity` | 5.0499 | 明暗落差极大，光照不匀显著 |
