## 0. 两份材料的关系(先看这个)

| 论文章节 | 说的内容 | 对应脚本输出 |

## 2. 方法 A:单张照片复现(最快出成果)

```bash
cd ~/Desktop/fastapi项目     # 本项目目录:脚本与照片都在这里
python document_image_analysis.py aebd26820104da5ac76f8c38e696dc9b.jpg --out_dir out_demo
# 需要插入报告的展示图时追加 --figures(依赖 matplotlib):
# python document_image_analysis.py aebd26820104da5ac76f8c38e696dc9b.jpg --out_dir out_demo --figures
```

产物(都在 `out_demo/`):
- `metrics.json` —— 9 项指标;
- `gray_histogram.png` —— 灰度直方图(纯 Pillow 绘制);
- `report_figure.png` —— 2×2 报告展示图:原图 + 灰度直方图 + 低频照度 L 伪彩 + 指标卡(仅 `--figures` 时生成);
- 终端同时打印 JSON。

### 2.1 指标速查(写报告/讲解时用)

| 字段 | 含义 | 对应论文 |
|---|---|---|
| `width / height` | 像素尺寸 | 2.1 |
| `rgb_mean` | 三通道均值 | 2.1 |
| `gray_mean` | 平均亮度(≈曝光) | 2.2 |
| `gray_std_contrast` | 对比度(std) | 2.2 |
| `laplacian_variance_sharpness` | 清晰度:标准 4-邻域 Laplacian 响应方差(VoL) | 2.2 |
| `lab_background_a_offset` | 近白区偏色轴 a*≈R−G | 2.2(近似,非真 Lab) |
| `lab_background_b_offset` | 近白区偏色轴 b*≈B−(R+G)/2 | 2.2(近似) |
| `illumination_nonuniformity` | (Lmax−Lmin)/Lmean,L=1/20 低频照度 | 2.4 |

> 说明脚本已做的“物理先验”处理:**偏色只统计 `灰度 > 60% 分位` 的近白像素**(避开文字/插图主导);**照度 L 用先缩小 1/20 再放大**的平滑图近似低频分量;**清晰度用标准 4-邻域 Laplacian 核** `[[0,1,0],[1,-4,1],[0,1,0]]`(数组切片实现,丢弃最外圈以避开边界伪影,故无需 scipy/opencv)。

> 与报告的对应关系写在脚本开头的“指标 → 论文章节对照表”里,评审可直接对照。

### 2.2 拍照建议(呼应论文第 4 节变量)

- 纸面尽量占满画面、四周有白边、留白大;
- 同一页分别拍:**暖光灯 / 冷白光 / 窗光**(色温)、**0°/15°/30°**(角度);
- 每类多拍几张,便于“同退化一致性与指标可复现性”的展示。

## 3. 方法 B:可控退化对照实验(证明“指标管用”)

目的:同一版式、只改退化 → 排除内容干扰,让指标差异归因于退化本身。

### 3.1 用现成样张生成脚本(已放桌面验证过)

> ⚠️ **提交范围提示**:`synthesize_samples.py`、`make_showcase.py` 属于桌面演示目录的临时脚本,**不在本项目提交物内**——作业要求辅助代码只能是一个 .py,提交时只交 `document_image_analysis.py`。展示图功能已并入该脚本的 `--figures` 参数。

```bash
cd ~/Desktop/document_analysis_demo
python synthesize_samples.py        # 生成 images/{normal,warm_shift,shadow,warm_shadow}.jpg
cd ~/Desktop
for n in normal warm_shift shadow warm_shadow; do
  python document_image_analysis.py "document_analysis_demo/images/$n.jpg" --out_dir "document_analysis_demo/out_$n"
done
```

四类退化模型(即论文 I_obs=I_illum·R·g_c+n):

| 样张 | 施加的退化 |
|---|---|
| ① normal | 均匀白光,基线 |
| ② warm_shift | 通道增益 R×1.14、B×0.82 → 暖色温偏色 |
| ③ shadow | 照度左上 1.08 → 右下 0.28 线性渐变 → 光照不匀 |
| ④ warm_shadow | ②+③ 叠加 |

### 3.2 已验证的判读规律(可直接抄进报告)

- 偏色轴 `b*`:②≈**−54**、④≈**−43**,而 ①/③≈0 → **b* 对偏色敏感、对纯阴影不敏感**;
- 不均匀度:③④≈**1.18 / 1.14**,约为基线(①≈0.41)的 **2.9 倍** → 对光照不匀敏感、对偏色不敏感;
- 清晰度(拉氏方差)在阴影下由 ~520 降至 ~310 → 乘性阴影压缩文字边缘梯度,支持“先保边照度补偿再 OCR”的流水线结论(论文 3/4 节)。

> 注:上述 520/310 为**早期二阶差分实现**下测得的数值。脚本现已改用标准 4-邻域 Laplacian,绝对量级会变大(同一张真实照片由 42.57 变为 205.04),但“阴影导致清晰度下降”的趋势不变;若要在报告中引用具体数字,请对合成样张重跑一次脚本刷新。

### 3.3 已知局限(写进论文是加分项)

1/20 缩略会把**密集文字块计入低频**,产生约 0.4 的恒定底噪(四张样张文字版式相同,故为常数,不掩盖阴影增量)。
改进方向正是论文 2.4 提到的:**形态学剔除文字后再估计 L / 引导滤波保边平滑**。

## 4. 成果展示怎么交

### 4.1 最小展示包(每张样张)

样张缩略图 + `gray_histogram.png` + 指标卡(9 项)。

### 4.2 对比展示图(推荐)

`document_analysis_demo/make_showcase.py` 一次运行产出三样:
- `showcase.png` —— 2×2 总览(样张+指标卡+直方图);
- `metric_bars.png` —— 偏色强度 √(a*²+b*²) 与不均匀度两幅条形对比;
- `report.md` —— 全指标 Markdown 汇总表 + 判读 + 局限。

**换成你自己的照片:** 把你的图放进 `document_analysis_demo/images/`,然后编辑 `make_showcase.py` 顶部:

```python
GROUPS = [
    ("你的文件1", "① 标签1"),
    ("你的文件2", "② 标签2"),
    # ... 想放几张放几张(网格会自动 2×2)
]
```

再运行:

```bash
cd ~/Desktop/document_analysis_demo
python make_showcase.py
```

展示脚本会自动读同名前缀的 `out_*` 目录(即需先按方法 A 对每张图跑出 `out_你的文件1/metrics.json`)。

### 4.3 进阶可视化(可选)

用 matplotlib 把 1/20 低频照度场画成伪彩热力图,标注 min/max 位置——直观展示“L 被估计出来”,呼应物理先验的可解释性。

## 5. 扩展到 240 张(数据收集方案落地)

```bash
cd ~/Desktop/fastapi项目
mkdir -p dataset_out
for f in 你的数据目录/*.jpg; do
  n=$(basename "$f" .jpg)
  python document_image_analysis.py "$f" --out_dir "dataset_out/$n"
done
```

汇总成 CSV(需 pandas,`pip install pandas`):

```python
import json, glob, pandas as pd
rows = []
for f in glob.glob("dataset_out/*/metrics.json"):
    rows.append(json.load(open(f)))
pd.DataFrame(rows).to_csv("dataset_out/summary.csv", index=False)
```

按论文第 4 节的对象分组(作业/试卷/板书/插图)算各指标均值/分位,即可画“偏色与光照不匀的分布统计”,支撑方案中的分层采样与双人标注一致性段落。
